1. CREAR CLASE Modifier.jack (archivo nuevo)
---------------------------------------------------------

Atributos:
    field int type;     // 0=ninguno, 1-6 tipo de modificador
    field int x, y;     // posicion actual (hereda la del bloque roto)
    field int size;     // tamano visual del comodin (ej. 8px)
    field int timer;    // contador de frames hasta que expira el efecto
    field boolean active; // true si el comodin fue capturado y esta activo
    field boolean onScreen; // true si todavia esta cayendo en pantalla

Constructor: Modifier.new(seed, xBloqueRoto, yBloqueRoto)
    - Calcula el tipo usando Random.range(seed, 1, 6)
    - Inicializa x = xBloqueRoto, y = yBloqueRoto
    - Inicializa timer = 300 (300 frames x 50ms = 15 segundos de efecto)
    - active = false, onScreen = true
    - Llama a draw()

Metodos:
    draw()      -> Screen.drawRectangle(x, y, x+size, y+size)
    hide()      -> Screen.setColor(false) + draw()
    move()      -> cae 3px hacia abajo cada frame mientras onScreen = true
                   si y > 255: let onScreen = false (salio de pantalla sin ser capturado)
    tickTimer() -> decrementa timer en 1; si timer = 0 el efecto expira
    getType()   -> return type
    getBottom() -> return y + size
    isOnScreen()-> return onScreen
    isActive()  -> return active
    activate()  -> let active = true; let onScreen = false; do hide()
    dealloc()   -> Memory.deAlloc(this)

2. CREAR CLASE Random.jack (archivo nuevo)
---------------------------------------------------------

Implementa un generador congruencial lineal (LCG):
    nextValue = (seed * 1664525 + 1013904223) mod 32767

Metodo estatico:
    function int range(int seed, int a, int b)
        // Retorna un numero entre a y b inclusive
        var int raw;
        let raw = ((seed * 1664525) + 1013904223);
        if (raw < 0) { let raw = -raw; }   // asegurar positivo
        return a + (raw - ((raw / (b - a + 1)) * (b - a + 1)));

NOTA: Jack usa enteros de 16 bits (-32768 a 32767), el overflow
es inevitable pero no es un problema — igual genera variedad suficiente.

5. LOGICA DEL TIMER Y CAPTURA DEL MODIFICADOR
   (donde conectar todo en BreakoutGame)
---------------------------------------------------------

CLASE: BreakoutGame.jack
METODO: moveBall() — al final del metodo, antes del return:

    // Mover comodin si esta cayendo
    if (modifier.isOnScreen()) {
        do modifier.move();

        // Verificar si el paddle lo capturo
        if ((modifier.getBottom() > paddle.getTop()) &
            (modifier.getLeft() < paddle.getRight()) &
            (modifier.getRight() > paddle.getLeft())) {
            do modifier.activate();
            do applyModifier();   // metodo nuevo, ver abajo
        }
    }

    // Tick del timer si el modificador esta activo
    if (modifier.isActive()) {
        do modifier.tickTimer();
        if (modifier.getTimer() = 0) {
            do revertModifier();  // metodo nuevo, ver abajo
        }
    }

NUEVO METODO applyModifier() en BreakoutGame:
    method void applyModifier() {
        var int t;
        let t = modifier.getType();
        if (t = 1) { do paddle.setWidth(paddle.getWidth() / 2); }
        if (t = 2) { do ball.increaseSpeed(3); }
        if (t = 3) { let switchKeys = true; }
        if (t = 4) { do paddle.setWidth(paddle.getWidth() * 2); }
        if (t = 5) { do ball.increaseSpeed(-2); }
        if (t = 6) { let piercing = true; }
        return;
    }

NUEVO METODO revertModifier() en BreakoutGame:
    method void revertModifier() {
        var int t;
        let t = modifier.getType();
        if (t = 1) { do paddle.setWidth(paddle.getWidth() * 2); }
        if (t = 2) { do ball.increaseSpeed(-3); }
        if (t = 3) { let switchKeys = false; }
        if (t = 4) { do paddle.setWidth(paddle.getWidth() / 2); }
        if (t = 5) { do ball.increaseSpeed(2); }
        if (t = 6) { let piercing = false; }
        return;
    }
